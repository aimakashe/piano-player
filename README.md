# PIANO-PLAYER
Интерактивное веб-приложение под названием pianoplayer, которое:
Предоставляет виртуальный интерфейс пианино.
Позволяет играть в реальном времени с помощью клавиатуры/мыши.
Записывает и сохраняет исполнение на пианино.
Воспроизводит заранее записанные песни.
Поддерживает импорт/экспорт исполнений в формате JSON

# Настройка npm и ESLint

npm init -y - Это создаст файл package.json
npm install eslint --save-dev -установка ESLint
