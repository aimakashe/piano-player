# 🎹 Piano Player — Development Roadmap

## ✅ Шаг 1: Настройка проекта и визуальная клавиатура
- [ ] Создать базовую структуру файлов (`index.html`, `style.css`, `script.js`)
- [ ] Реализовать HTML-разметку клавиатуры пианино (минимум 2 октавы, 24 клавиши)
- [ ] Добавить CSS-стили для клавиатуры (черные/белые клавиши, расположение)
- [ ] Настроить `npm` и `ESLint`

---

## 🎵 Шаг 2: Базовая генерация звука (Web Audio API)
- [ ] Инициализировать `AudioContext`
- [ ] Реализовать функцию для маппинга ноты (`C3`, `F#4` и т.д.) в частоту (Гц)
- [ ] Создать функцию `playNote` для генерации звука (например, синусоидальный сигнал с атакой/затуханием)

---

## ⌨️ Шаг 3: Ввод с клавиатуры и мыши
- [ ] Добавить обработку кликов мыши по клавишам
- [ ] Реализовать обработчики событий `keydown` и `keyup` для управления с клавиатуры
- [ ] Сопоставить клавиши клавиатуры с нотами (таблица маппинга)
- [ ] Добавить визуальное выделение клавиш при нажатии

---

## 🎙️ Шаг 4: Функциональность записи
- [ ] Реализовать логику начала и остановки записи
- [ ] Захватывать `key`, `startTime` (от начала записи) и вычислять `duration`
- [ ] Добавить визуальную обратную связь во время записи

---

## 📦 Шаг 5: Экспорт / Импорт JSON
- [ ] Реализовать функцию преобразования записанных данных в формат `JSON`
- [ ] Добавить возможность скачивания `JSON` файла
- [ ] Реализовать загрузку `JSON` файла через `input type="file"`

---

## ▶️ Шаг 6: Система воспроизведения (Prepared Mode)
- [ ] Добавить элементы управления: `Play`, `Pause`, `Stop`
- [ ] Использовать `setTimeout` / `setInterval` для точного воспроизведения нот по времени
- [ ] Добавить регулировку скорости воспроизведения
- [ ] Подсвечивать клавиши во время проигрывания

---

## 🎨 Шаг 7: Полировка и UI
- [ ] Добавить адаптивный дизайн (`Media Queries`)
- [ ] Реализовать индикатор прогресса и отображение предстоящих нот
- [ ] Создать интерфейс для переключения режимов (игра / запись / воспроизведение)
